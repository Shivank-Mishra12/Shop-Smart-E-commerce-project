## 📌 Project Overview

This project predicts whether a website visitor will generate **revenue (purchase)** or not using Machine Learning techniques.
It helps businesses understand customer behavior and improve conversion rates.

---

## 🎯 Problem Statement

In e-commerce platforms, not every user makes a purchase.
The goal is to build a model that can:

* Predict **Revenue (1)** → User will purchase
* Predict **No Revenue (0)** → User will not purchase

---

## 🧠 ML Approach

* Data Preprocessing (handling categorical + numerical data)
* Feature Scaling
* Model Training using:

  * Logistic Regression
  * KNN
  * Random Forest
* Ensemble Learning (Voting Classifier)
